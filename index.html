A few useful answers

A few questions,
before you begin.

A little about the method, the material it can work with, and what this project actually provides.

What is the Feynman Technique?

It is a learning approach built around explaining an idea in simple language, noticing where the explanation breaks down, returning to the missing knowledge, and explaining it again. The aim is understanding, not merely repeating a definition.

Does the assistant explain before asking questions?

Yes. For a normal learning request, it first gives a beginner-friendly explanation and then invites the learner to teach it back. It can test first when the learner explicitly requests that.

Can I study from a PDF, book, webpage, video, or image?

The skill supports learning from these materials when the host AI agent can access and interpret them. Video transcription, PDF extraction, webpage browsing, and image reading are capabilities of the host agent, not built into this instruction package.

Is Feynman Learning Companion a standalone app?

No. It is a portable set of instructions for compatible AI agents. It does not include its own AI model, chat interface, file-processing service, or persistent learner database.

Where can I get the skill?

The complete skill is available in the public GitHub repository. Download the repository and follow its installation instructions.
