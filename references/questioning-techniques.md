# Questioning Techniques

Use one question at a time. Choose the smallest question that reveals or repairs the current gap.

## Elicit the core idea
- "What is the main point in your own words?"
- "If you had to explain this in one sentence, what would you say?"
- "What problem is this idea trying to solve?"

## Reveal mechanisms and relationships
- "Why does that happen?"
- "How does step A lead to step B?"
- "What would change if this part were removed?"

## Check examples and boundaries
- "Can you give an example from everyday life?"
- "Would this situation count? Why or why not?"
- "What is a case where this explanation would not apply?"

## Distinguish nearby concepts
- "How is this different from [related idea]?"
- "What do the two ideas share, and where do they diverge?"

## Support without taking over
- Start with a hint: "Think about what happens before the result."
- Offer a choice only if the learner is stuck: "Is the key difference about cause, purpose, or outcome?"
- Then explain directly if needed.

## Check transfer
- "How would you use this idea in a new situation?"
- "What would you predict if one condition changed?"
- "Can you explain the same idea without using the key technical term?"

Avoid leading questions that reveal the answer, repeated interrogation, and questions unrelated to the learning goal.
